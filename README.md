# Thermal Analysis and Design of a 50 W Electronics Heatsink

## Project Overview
This project focuses on the design and thermal analysis of a passive aluminium heatsink for a hypothetical 50 W electronics module.

The objective is to investigate the heatsink's thermal performance under natural convection using analytical heat-transfer calculations and ANSYS thermal simulation.

## Project Objectives
- Design a heatsink using CAD.
- Perform analytical heat-transfer calculations.
- Conduct steady-state thermal analysis using ANSYS.
- Investigate temperature distribution and thermal resistance.
- Study mesh convergence and the influence of boundary conditions.
- Explore design improvements to enhance thermal performance.

## Tools
- CAD: Autodesk Inventor
- Simulation: ANSYS
- Engineering calculations: Python / Excel

## Project Status
In progress.

## Disclaimer
This is an academic engineering project based on a hypothetical electronics module. The results will depend on the geometry, material properties, and simulation assumptions.
